# IA EN MAIN — module prospect

Présentation à glisser + questionnaire, une page par prospect.

- Ajouter un prospect : créer `src/clients/<slug>.json` (copie de `sherazade.json`), puis `python3 src/build.py <slug>`.
- Page publiée : `https://nolandiliegro-ops.github.io/ia-en-main/<slug>/`
- Réponses : table Supabase `iaem_reponses` (projet lemas), insertion publique seule.
